# 판결 비교 — 시안 구도 재현 v2

기존 `verdict-react-demo`는 그대로 두고 새로 만든 독립 React 프로젝트야.

## 먼저 보기

압축파일에 함께 들어 있는 `verdict-react-v2-preview.html`을 브라우저에서 열어봐. React, 스타일, 에셋이 모두 포함되어 있어 설치 없이 실행돼.

- 정지 화면: 최종 구도와 캐릭터 크기를 확인해.
- 애니메이션: 판멍이 등장 → 투표지 곡선 이동 → 왈가닥이·비율 공개.
- 다시 보기: 약 3초의 등장 연출을 다시 재생해.
- 판단 근거 보기: 상세 설명을 펼쳐.

## 개발 실행

```sh
npm ci
npm run dev
```

```sh
npm run build
```

## 기존 React에 옮기기

`src/VerdictScene.jsx`, `src/VerdictScene.css`, `src/assets/`를 같은 새 폴더로 복사해.

```jsx
import VerdictScene from './verdict-v2/VerdictScene.jsx';

<VerdictScene
  juryPercent={61}
  aiReason="실제 사건의 AI 판단 근거"
  still={false}
/>
```

이 컴포넌트는 종결 사건 중 **AI=글쓴이 / 배심원=상대방** 상황 전용이야. 비율이 없으면 숫자를 숨기고, 근거가 없으면 근거 영역을 숨겨. 61%와 데모 문구는 시안용이니 실제 값으로 교체해.

Next.js App Router에서는 첫 줄에 `'use client';`를 추가하고 해당 프로젝트의 PNG import 규칙에 맞춰 `.src` 또는 public URL을 사용해. 제공 프로젝트는 Vite 기준이야.

## 에셋 구성과 정확한 한계

- `panmung-raised-hand.png`: 참고 시안의 손 든 포즈를 이미지 생성 도구로 복원한 이미지. 원본 픽셀을 그대로 추출한 것은 아니야.
- `stage-background.png`: 캐릭터·텍스트 없는 입체 무대와 파랑/주황 곡선 배경을 복원한 이미지.
- `wallang-author.svg`, `walgadak-opponent.svg`: 기존 피그마의 2D 벡터 그대로. 형태·표정·색상 변경 없음.
- `panmung-matte.svg`: 흰색 판멍이 이미지의 외곽을 분리하는 CSS용 벡터 마스크. PNG 자체는 **불투명**이야. CSS와 마스크를 반드시 같이 사용해. 경계에 미세한 흰 여백이 있어 흰색/밝은 배경용 시안이야.
- 투표지는 JSX 안의 SVG `defs`/`use`로 제작했고, `animateMotion` 경로를 따라 움직여. 화면에 남는 연한 투표지 흔적은 정적인 장식이야.

원본 시안의 스마트폰 테두리와 하단 설명용 스토리보드는 앱 콘텐츠에서 제외했어. 캐릭터 크기·손 위 아이콘·입체 무대·결과 비율·곡선 투표지 구도를 재현했으며 원본 이미지와 픽셀 단위 일치를 보장하지는 않아.

## 접근성과 동작

- 화면 진입과 이미지 로드를 기다려 한 번 재생해.
- 모션 줄이기 설정에서는 정지 결과를 바로 보여줘.
- 시각 연출은 보조 장식으로 처리하고 결과는 스크린리더용 문장으로도 제공해.
- 재생 버튼 포커스 유지, 실제 버튼과 details 사용.
- 장식 투표지 개수는 실제 득표 수가 아니야.
- 사용자에게 실제 투표를 요청하거나 결과 데이터를 바꾸지 않아.

## 확인 완료

- Vite 프로덕션 빌드 통과.
- Chromium에서 이미지 로딩, 콘솔 오류 없음 확인.
- 재생 도중 투표지 표시, 다시 보기, 정지 화면 전환, 근거 펼치기 확인.
- 모션 줄이기 시 SVG 애니메이션 제거 및 재생 버튼 비활성화 확인.
- 402px 및 320px 화면 확인, 가로 스크롤 없음.

삭제할 땐 해당 컴포넌트 import/사용 부분과 이 폴더만 삭제하면 돼. 기존 시안 폴더와 기존 피그마는 변경하지 않았어.

## 복원 프롬프트 요약

내장 이미지 생성 도구 사용. 판멍이: 참고 시안의 손을 든 포즈와 법복·망치를 유지하고 아이콘/배경/텍스트 제거. 무대: 캐릭터 없는 아이보리 타원 받침대와 좌측 파랑·우측 주황 곡선, 흰 배경. 투명 생성 결과가 불투명 체크무늬여서 폐기하고 순백 배경으로 수정한 뒤 런타임 SVG 마스크 적용.
