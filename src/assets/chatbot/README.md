**넣지 않은 이유**

- GitHub의 파일 크기 하드 제한이 100 MB라 푸시 자체가 거부된다.
- 56px 아이콘 하나에 JS 번들(455 kB)의 300배를 싣게 된다.
- three.js로 실시간 렌더하면 공용 `package.json`에 런타임 의존성이 생긴다.
  (`PROJECT_SPEC.md` §7-11 — 새 라이브러리는 요청이 있을 때만)

원본 파일은 디자인 담당자가 보관한다. 저장 위치는 팀에서 정한다. → 확인 필요

### 시트를 다시 굽는 방법

프레임 수·크기·각도·조명을 바꾸려면 아래 과정을 다시 거친다.

1. `AIchat360.glb`를 로컬 정적 서버로 서빙한다.
2. three.js `GLTFLoader`로 불러와 전체 바운딩 박스의 중심을 원점으로 옮긴다.
3. 직교(orthographic) 카메라로 정면에서 본다. 프레임 반지름은
   `max(hypot(rx, rz), height / 2) × 1.02`로 잡는다. 회전 중 가장 넓어지는
   실루엣을 기준으로 해야 어느 각도에서도 잘리지 않는다. (여기서는 3.27)
4. 모델을 Y축으로 `i / 180 × 2π`씩 돌려가며 128px 캔버스에 그리고
   15열 격자로 이어 붙인다.
5. 알파를 살려 WebP로 저장한다.

GLB의 애니메이션 트랙은 쓰지 않는다. rotation 단일 채널이라 코드에서
같은 속도로 돌리면 결과가 같다.
